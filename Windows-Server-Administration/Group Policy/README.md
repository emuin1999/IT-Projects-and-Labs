# Configuring Group Policy

Objective: Apply security restrictions through Group Policy.

What I did:
- Configured a Group Policy for password policy.
- Configure Account Lockout Policy.
- Restrict control Panel.
- Configure Automatic Network Drives.
- Configure Network Drives using Item level Targeting.
- Configure Drives using group policy preferences
- Applied the policy to the appropriate domain environment.
- Used gpupdate /force to refresh Group Policy.
- Verify that GPOs works(control panel).

## What I Learned:
By the end of this project, I learned how to configure and manage Group Policy Objects (GPOs) in a Windows Server Active Directory environment. I gained hands-on experience creating security policies to control how users interact with domain computers and manage access to network resources.

I learned how to configure password policies and account lockout policies to improve account security and help protect against unauthorized access. I also practiced restricting Control Panel access to prevent users from making unwanted changes to system settings.

Additionally, I learned how to use Group Policy Preferences to automatically map network drives for domain users. I explored Item-Level Targeting, which allows administrators to assign specific network drives based on user or group membership.

Finally, I learned how to link GPOs to the appropriate Organizational Units, refresh policies using the gpupdate /force command, and verify that the policies were successfully applied to the Windows 11 client machine.
