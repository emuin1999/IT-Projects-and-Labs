# Project: Creating and Documenting a Support Ticket in Spiceworks

## Objective
Practice using a help desk ticketing system to document, troubleshoot, and resolve a user account lockout issue.

## Project Overview
A user was unable to sign in to their Windows account because their Active Directory account was locked after multiple failed login attempts.

As the help desk technician, I used Spiceworks to manage the support ticket, investigate the issue, unlock the user's account, reset their password, communicate with the user, and document the resolution.

## Tools & Technologies Used
- **Spiceworks:** Created, managed, and documented the support ticket.
- **Active Directory Users and Computers (ADUC):** Located the user's account and unlocked it.
- **Windows Server:** Managed Active Directory user accounts.
- **Microsoft Active Directory:** Investigated and resolved the account lockout.

## What I Did

1. **Created a Support Ticket:** Created a ticket in Spiceworks for a user who could not sign in due to multiple failed login attempts.
2. **Reviewed the Issue:** Examined the user's description and attached screenshot showing the account lockout error.
3. **Accepted the Ticket:** Accepted the support request as the assigned help desk technician.
4. **Unlocked the Account:** Used Active Directory Users and Computers (ADUC) to locate the user's account and unlock it.
5. **Reset the Password:** Reset the user's password to restore account access.
6. **Communicated with the User:** Notified the user that the issue had been addressed and requested confirmation.
7. **Verified the Resolution:** Received confirmation from the user that they could successfully sign in and update their password.
8. **Documented and Closed the Ticket:** Recorded the troubleshooting steps and final resolution in Spiceworks before closing the ticket.

## What I Learned

I learned how to handle a help desk ticket from the moment a user reports an issue until the ticket is resolved and closed.

This scenario helped me understand how to troubleshoot Active Directory account lockouts using Active Directory Users and Computers (ADUC). I practiced locating a user's account, unlocking it, and resetting their password to restore access.

I also learned the importance of communicating with users throughout the troubleshooting process. After resolving the issue, I notified the user, requested confirmation that they could sign in successfully, and verified that they had updated their password.

Finally, I learned how important accurate ticket documentation is for tracking technical issues, recording troubleshooting steps, and maintaining a clear history of support activities.

This project strengthened my understanding of help desk responsibilities, Active Directory account management, customer communication, and the ticket lifecycle.
