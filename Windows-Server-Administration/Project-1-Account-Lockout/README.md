# Creating and Documenting a Support Ticket in Spiceworks
Objective: Practice using a ticketing system to document and track a user account lockout issue.

What I did:
- Created a support ticket in Spiceworks for a user who was unable to sign in due to multiple failed login attempts.
- Documented the user's reported issue.
- Recorded the troubleshooting steps taken to investigate the account lockout.
- Used the ticket to track the issue and document the resolution.
