# Installing Active Directory Domain Services

Objective: Install the AD DS role and configure Windows Server as a domain controller.

What I did:
- Download and Installed Window Server On VMware
- Installed the Active Directory Domain Services role.
- Promoted Windows Server to a domain controller.
- Created the wintip.local domain.

What I Learned:
- Established the foundation for setting up Active Directory Domain Services (AD DS) and managing domain users and computers.
- Prepared Windows Server to function as a Domain Controller.
- Established the ability to manage the server through the organization's domain environment.
- Established centralized authentication and domain-based management.
