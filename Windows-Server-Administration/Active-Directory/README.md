# Installing Active Directory Domain Services

Objective: Install the AD DS role and configure Windows Server as a domain controller.

What I did:
- Download and Installed Window Server On VMware
- Installed the Active Directory Domain Services role.
- Promoted Windows Server to a domain controller.
- Created the wintip.local domain.

## What I Learned:
Through this project, I learned how to create and configure a Windows Server virtual machine using VMware. I gained hands-on experience installing Windows Server and setting up the environment for Active Directory management.
I also learned how to install Active Directory Domain Services (AD DS) and the necessary Windows administrative tools. I practiced configuring the server to communicate with the Domain Controller and joining it to the wintip.local domain.
This project helped me understand how Windows Server provides centralized management of users, computers, and network resources within an organization.
